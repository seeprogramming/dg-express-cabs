7. SERVER-RENDERED HTML VS CLIENT-SIDE JAVASCRIPT
================================================================================
CRITICAL SEO DEFICIENCY:
1. On `/cabs/[route]`:
   - In `CabSearch.tsx`, `const [hasSearched, setHasSearched] = useState(false);`.
   - The entire vehicle selection panel (`<section id="resSec">`), which contains all vehicle categories (Sedan, Ertiga, Innova, Crysta), seat capacity, luggage limits, and exact fares, is CONDITIONAL ON `hasSearched === true`.
   - On initial server render, `hasSearched` is FALSE.
   - Consequently, the initial HTML delivered to Googlebot and other web crawlers CONTAINS NO VEHICLE RATES, NO VEHICLE COMPARISONS, AND NO PRICING TABLE!
   - Crawlers only see the hero text and a 2-sentence "Why book" blurb. This severely impairs rankings for searches like "Pune to Mumbai cab fare", "Innova Crysta Pune to Mumbai price", etc.
2. On `/cabs`:
   - Initial HTML only renders the 32 one-way routes.
   - The 8 round-trip routes and 3 local rental plans are completely hidden until a user clicks client-side buttons. Search engine bots do not trigger these state changes.
3. On `/cabs/details` & `/booking`:
   - The entire page depends on `useSearchParams()`. Without JavaScript execution and active URL query params, the page defaults to blank/fallback dummy states.

8. DUPLICATE & THIN PAGE RISKS
================================================================================
1. Duplicate Page Pair: `/cabs/details` and `/booking`
   - Both pages render the identical `<CabDetails />` component.
   - Having two active URLs for the exact same function creates duplicate content and cannibalization.
2. Query Parameter Pollution on `/cabs/details`:
   - Every search interaction generates URLs like `/cabs/details?vehicle=Sedan&model=Dzire&seats=4&bags=2&from=Pune&to=Mumbai&price=2730`.
   - Search engines crawling these URLs find identical thin content with minor parameter swaps.
   - Currently, `/cabs/details` is in `sitemap.ts` and lacks a `noindex` tag.
3. Thin Content on Route Pages (`/cabs/[route]`):
   - All 32 route pages share identical boilerplate text ("Whether traveling for business, family vacation, or leisure...").
   - There are no route-specific FAQs, no driving distance (km), no estimated travel duration (hours), no toll/expressway notes, and no unique destination landmarks.
   - As noted in Section 7, the pricing table is not in the server-rendered HTML.
4. Bidirectional Route Cannibalization:
   - For example, `/cabs/pune-to-mumbai` and `/cabs/mumbai-to-pune` have identical templates and pricing. Without distinct location-specific context (e.g. Pune pickup hubs vs Mumbai drop points, Expressway tips), search engines may consider them duplicate thin variants.
5. Tour Packages with Missing Itineraries:
   - Several 1-day packages (e.g. single-day Ashtavinayak circuits) have no structured day-by-day itinerary, rendering only a route sequence and a 1-sentence description.
